Sistema de Alerta Temprana para la Agricultura Boliviana

Monitoreo de Plagas y Enfermedades en Cultivos Bolivianos mediante modelado agroclimático integral y evaluación de vulnerabilidad para la agricultura familiar.

Socios Estratégicos del Proyecto

Ejecutado por Alliance of Bioversity International & CIAT en conjunto con YAPU Solutions protegiendo la agricultura boliviana.

Presentación del Proyecto

El presente proyecto tiene como objetivo desarrollar e implementar un Sistema de Alerta Temprana (SAT) para el monitoreo de plagas y enfermedades en cultivos clave de Bolivia. Este sistema está diseñado para anticipar brotes epidemiológicos mediante el análisis de condiciones climáticas históricas y pronósticos estacionales, permitiendo a los agricultores e instituciones tomar medidas preventivas.

Fase de Inicio

Definición de Cultivos de Interés y Áreas de Estudio

Objetivo y Proceso

Identificar las principales áreas agrícolas y cultivos clave para el análisis de plagas y enfermedades en Bolivia. Se parte de un análisis exhaustivo de datos agrícolas de fuentes oficiales (INE, MDRyT) e internacionales (FAOSTAT).

Utilizamos Sistemas de Información Geográfica (SIG) para delinear áreas de producción por municipio, priorizando por importancia socioeconómica y exposición climática.

Entregables

Informe Inception: Análisis de datos BDP y extrapolación de implicaciones para la seguridad alimentaria regional.

Análisis Epidemiológico

Identificación de Principales Plagas y Enfermedades

Objetivo y Proceso

Determinar las plagas y enfermedades más relevantes que afectan a los cultivos seleccionados. Se desarrolla un perfil biológico de cada amenaza, incluyendo ciclo de vida y síntomas.

Este análisis se valida mediante encuestas a expertos agrónomos y técnicos locales bolivianos para priorizar aquellas amenazas con mayor impacto en el rendimiento de los cultivos.

Entregables

Catálogo de Plagas: Compendio detallado de condiciones ambientales óptimas y umbrales críticos para cada patógeno.

Ingeniería de Datos

Generación de Indicadores Agroclimáticos

Objetivo y Proceso

Desarrollar indicadores bio-meteorológicos que representen las condiciones favorables para la aparición de plagas. Se utilizan datos históricos de CHIRPS (precipitación) y AgERA5 (temperatura/humedad).

Mediante análisis multivariable, se establecen los algoritmos que detectan secuencias climáticas de riesgo, calibrados con registros históricos de incidencia en campo.

Entregables

Paquete de Índices: Algoritmos validados de riesgo agroclimático, listos para procesamiento automatizado.

Análisis Espacial

Análisis Espacio-temporal de Vulnerabilidad

Objetivo y Proceso

Evaluar la vulnerabilidad de las regiones agrícolas bolivianas con una resolución espacial de 5 km. Se integran los índices agroclimáticos con mapas de uso de suelo actualizados.

El resultado es una zonificación dinámica que identifica áreas de alto riesgo basándose en la coincidencia de etapas críticas del cultivo y condiciones climáticas extremas.

Entregables

Mapas de Vulnerabilidad: Capas geoespaciales de alta resolución que muestran el perfil histórico de susceptibilidad.

Servicio de Alerta

Pronósticos Estacionales y Evaluación del Riesgo

Objetivo y Proceso

Implementar el motor de pronóstico utilizando Análisis de Correlación Canónica (CCA) para predecir condiciones a escala estacional.

Los pronósticos se traducen a alertas tempranas accionables, permitiendo a las instituciones gubernamentales y productores planificar medidas preventivas antes de la aparición del brote.

Entregables

Motor SAT (Forecasting Engine): Código documentado y rutinas operativas integrables para la emisión periódica de alertas.

💻 Generador de Series Históricas Climáticas para Bolivia (1981-2025)

Este proyecto contiene una colección de scripts en R diseñados para procesar, estandarizar y generar una serie histórica de mapas climáticos diarios para Bolivia, abarcando el periodo comprendido entre 1981 y 2025.

El objetivo principal de este flujo de trabajo es armonizar variables climáticas provenientes de diferentes fuentes (CHIRPS y AgERA5) para que compartan la misma extensión espacial, sistema de coordenadas y una resolución espacial unificada de 5 km.

📊 Datos Utilizados

  • CHIRPS v3: Precipitación diaria. Base grid a 5 km de resolución. Recorte espacial y limpieza de datos.
  • AgERA5 versión 2: Temperatura Máxima, Temperatura Mínima, Humedad Relativa, PET y VPD. Conversión de unidades y reescalado a 5 km.

⚙️ Metodología (Flujo iterativo)

  • Carga de límites: Shapefile de Bolivia (sf).
  • Raster base: Mapa diario de CHIRPS.
  • Recorte y Máscara: Crop & Mask a los límites de Bolivia.
  • Transformación: Limpieza y conversiones.
  • Remuestreo: Resample a 5 km (método bilinear).

🛠️ Requisitos del Sistema

Instalación en R:

install.packages(c("terra", "sf", "sp"))

* terra: Manejo raster, sf: Datos vectoriales.

🐍 Visualización de Variables Climáticas Históricas

Este proyecto proporciona un Notebook interactivo en Python diseñado para explorar, analizar y visualizar las variables climáticas históricas previamente procesadas para Bolivia.

El objetivo principal es brindar una herramienta accesible en la nube (Google Colab) que permita a los investigadores y técnicos generar mapas, gráficos de series temporales y mapas de calor interactivos, sin necesidad de configuraciones locales complejas.

📊 Datos Utilizados

  • Datos Geoespaciales (Rasters): Archivos GeoTIFF derivados del procesamiento previo (CHIRPS y AgERA5) a 5km de resolución.
  • Variables Analizadas: Precipitación, Temperaturas (Máxima, Mínima), Humedad Relativa y Evapotranspiración.
  • Datos Vectoriales: Shapefiles a nivel departamental y municipal de Bolivia para el enmascaramiento y agrupación de datos.

⚙️ Metodología (Flujo de trabajo)

  • Ingesta de Datos: Conexión con Google Drive para acceso directo a los repositorios de datos climáticos (`.tif`).
  • Procesamiento Geoespacial: Uso de librerías especializadas para la lectura eficiente de cubos de datos espaciotemporales.
  • Análisis Estadístico: Agregación espacial zonal y cálculo de anomalías históricas usando herramientas analíticas como Pandas.
  • Visualización Dinámica: Creación de paneles gráficos (dashboards) e impresión de mapas estáticos detallados.

🐍 Modelos Agroclimáticos en Python (pronóstico a 16 días)

Versión en Python de los Modelos Agroclimáticos en R, adaptada para trabajar con el pronóstico climático diario por municipio (Open-Meteo). Cada script calcula el índice de riesgo de una plaga o enfermedad con la misma fórmula, pesos y semáforo que su versión en R.

Los índices se calculan por municipio productor, sobre una ventana fija con los primeros días del pronóstico, para cada modelo climático y para el multimodelo. Como el pronóstico se actualiza a diario, las alertas también.

🚀 Uso

  1. Descargar el script del cultivo y el archivo de pronóstico pronostico_latest.json.
  2. Descargar la lista de municipios productores cultivos_municipios.json.
  3. Ejecutar indicando ambas rutas; el resultado es un CSV por municipio y modelo.
python Script_Indice_Riesgo_Papa_Pronostico.py --pronostico pronostico_latest.json --cultivos cultivos_municipios.json --salida resultados/

🛠️ Requisitos del Sistema

Python 3.9 o superior:

pip install numpy pandas

* correr_modelos.py ejecuta todos los modelos y genera el archivo de alertas que usa esta página.

# Proyecto: Modelos Agroclimáticos en R 🌾🌡️

## 📖 Descripción del Proyecto

Este subproyecto contiene todos los scripts en lenguaje **R** utilizados para el cálculo y desarrollo de los **Modelos Agroclimáticos** (Índices de Riesgo Espacial) de diferentes cultivos de importancia para Bolivia. 

Cada script está diseñado para procesar datos climáticos y calcular índices de riesgo fitosanitario (plagas y enfermedades) a nivel espacial para un cultivo específico, generando mapas y resultados útiles para la toma de decisiones agrícolas.

## 🚀 Uso

Para trabajar con estos scripts:
1. Abre el archivo **`Modelos_Agroclimaticos_R.Rproj`** en RStudio. Esto establecerá el directorio de trabajo (working directory) correcto.
2. Abre el script del cultivo deseado.
3. Asegúrate de tener los datos de entrada (datos climáticos y espaciales) correspondientes antes de ejecutar el código.
